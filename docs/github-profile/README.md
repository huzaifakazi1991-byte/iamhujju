## ⚡ What I'm building now

**[IAMHUJJU](https://iamhujju.com)** — a production multi-provider AI SaaS
(Le Chat style), live at [iamhujju.com](https://iamhujju.com):

- 🔌 **Provider-agnostic AI gateway** — paste any provider API key in an admin
  panel and that provider's models go live instantly. Keys are AES-256-GCM
  encrypted at rest; nothing sensitive ever leaves the server.
- 🛡️ **Server-side gating on every request** — auth → plan → rate limit →
  token balance, enforced atomically with an append-only usage ledger.
- 💬 **Chat / image / video playground** with capability-aware metering.
- 💳 **INR billing** through Razorpay (Pro ₹1,299 · Business ₹8,999) on a
  Neon Postgres + Render free-tier stack.
- 🛠️ **Full admin panel** — models, plans, users, live provider health.

## 🧠 How I work

<small align="left">

1. **Direct** — I plan the milestone, then hand it to autonomous coding agents
   with precise, testable prompts.
2. **Engineer prompts, not just code** — system design, guardrails, and
   verification steps are written into every agent brief.
3. **Verify independently** — every change passes typecheck, unit tests, e2e
   smoke, and adversarial suites before it reaches production.
4. **Own the outcome** — CI, deploys, live-site verification, and post-launch
   fixes are all part of the loop.

</small>
